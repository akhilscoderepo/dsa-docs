## Unlocked Combinations

One combination can be taught now because every piece of it has already appeared in this chapter. A second is named as deferred, along with the chapter that supplies what it lacks.

### Teach Now

A stack together with parsing state is the twelfth lesson. The parser supplies the meaning of each token and the position in the grammar, and the stack keeps the unresolved remainder of every enclosing level. The lesson uses one loop shape on four kinds of text: a postfix formula measured by its peak stack height, a compressed repeat note measured by its decoded length without building it, a file path cleaned by an explicit stack of directory names, and a bracketed formula measured by its result and its nesting depth. The ladder goes from a counted stack, through saturating lengths, to the boundary where a path tries to climb above the root, and ends with a calculator that carries two answers. The false friend is splitting the text at separators, which cannot represent nesting.

### Deferred

Stacks that discard dominated entries, such as the next greater element or the largest rectangle in a histogram, rely on a stronger invariant about the order of the values kept. Chapter 12 introduces that ordered-stack invariant and owns the next-greater, histogram and contribution-counting problems, so no exercise here depends on it. The stacks in this chapter keep every unresolved entry and never throw one away because it cannot be an answer.

### Already Covered

Reading digits into a number and carrying a running total through a loop were taught in the arrays and strings chapters. The idea of marking a state when it is first seen, which keeps a search from repeating work, appears here for queues and returns in the hash-map chapter as a set of seen keys. Boundary thinking about empty input, a single element and extreme values follows the habits set from the first chapter on.
