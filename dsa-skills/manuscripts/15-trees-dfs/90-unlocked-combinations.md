## Unlocked Combinations

A report that needs three numbers from one tree should not walk the tree three times. This chapter releases one pairing that its lessons already support, and it names one pairing that waits for the next chapter.

### Pairing Taught In This Chapter

A tree and the return values of a depth-first walk form the lesson Return Results From Subtrees. The tree gives each call a subtree to own. The returned record gives the parent the few numbers it needs from a finished subtree. The lesson adds one idea: the answer formed at a node and the value returned from it are different numbers, and a record can carry both a branch for the parent and a running best for the whole tree. Its exercises change the record in four ways: a count beside the depth, a cost on each edge, a tolerance in the balance rule, and a path that must have two nodes.

### One Pairing Waits For The Next Chapter

A tree walk that must report nodes grouped by distance from the root needs a queue that holds one level at a time. A depth-first walk does not keep levels together, so the pairing cannot be built from this chapter alone. Chapter 16 teaches the level-by-level queue and owns the problems of that pairing, and this chapter assigns none of them.
