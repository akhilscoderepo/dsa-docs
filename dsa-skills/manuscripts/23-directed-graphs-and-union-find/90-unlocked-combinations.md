## Unlocked Combinations

This chapter releases one combination with a lesson of its own and names one as deferred, together with the chapter that supplies what it still lacks.

### Teach Now

A graph read together with a disjoint-set structure is the eighth lesson. The graph contributes edges as connectivity events, each of which says that two things now belong together. The structure contributes one representative per evolving group, so that each event costs almost nothing and each question is a comparison of two representatives. The care is needed in what the two keep in step: the count of groups, the sizes, and the decision of when an edge is redundant. The ladder re-asks four familiar problems with changed contracts: friendship pairs reported as sorted group sizes, a general graph that counts its redundant edges, accounts merged through shared emails with only summary figures reported, and a spanning tree under Chebyshev distance. The false friend is the shortcut that infers the group count from the vertex and edge totals.

### Deferred

Shortest paths on weighted graphs need distances that improve as better routes are found, which is relaxation and not merging. That is owned by Chapter 24, so no weighted path exercise appears here. The spanning-tree lesson only touches weights to order edges, and a heap-driven alternative for it waits for the same chapter.
