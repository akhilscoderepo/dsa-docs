## Unlocked Combinations

A search box suggests the three most used phrases for each typed prefix. A ride service must find a waiting driver after riders cancel, drivers go offline and trips finish. The first service needs a trie that also carries ranking data. The second needs several indexes that agree after each call. The two closing lessons pair the techniques that make both work.

These lessons combine the prefix, ledger, feed and lifecycle techniques from the seven lessons before them.

### Pairings Taught In This Chapter

| Combination | Representative problem |
| --- | --- |
| Trie + Ranked Service | LeetCode 677 Map Sum Pairs and LeetCode 642 Design Search Autocomplete System |
| Simulation + Multiple Indexes | LeetCode 348 Design Tic-Tac-Toe and LeetCode 3829 Design Ride Sharing System |

The lesson Rank Words By Prefix requires every prefix node to repair its ranked list whenever a count changes. The lesson Keep Several Indexes In Step requires one writer that removes the old record and inserts the new one in every index.

### Deferred Pairing

Concurrent service state is not taught here. Safe access from several threads belongs to the later concurrency curriculum, so each class in this chapter assumes one caller at a time.
