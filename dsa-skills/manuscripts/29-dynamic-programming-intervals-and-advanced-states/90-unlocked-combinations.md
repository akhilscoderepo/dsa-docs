## Unlocked Combinations

A scheduler assigns twelve jobs to twelve machines by trying every order and finishes after a day. A table over the set of used machines finishes in milliseconds, but only when the set is part of the state. Joining a recurrence with a richer state is what this chapter releases, where a pairing is a lesson that merges earlier topics into one decision.

### Pairing Taught In This Chapter

The lesson DP With Advanced State joins the recurrence habit from the foundations chapters with the range, prefix and mask encodings from the first lessons. The recurrence supplies the reuse of earlier answers. The encoding says which subproblem each stored answer belongs to. The lesson adds one idea: choose the index so that everything outside the stored answer is already fixed. Its four exercises count palindromic subsequences in query ranges, cut a string into pieces of a minimum length, burst items with given outer values, and split numbers into groups of equal sum.

### Pairing That Waits For A Later Chapter

Speedups that cut the number of transitions, such as Knuth optimization, divide and conquer optimization and the convex hull trick, hold only for recurrences with a proven structure. Each needs its own proof and a decision about who owns it. A later chapter takes them, and this chapter assigns no problems to them.
