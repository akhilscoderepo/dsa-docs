## Unlocked Combinations

A strategy simulator earns a profit on paper that no real account could reach, because it sells a share on the same day it buys again. The fix lies in the table and not in the loop: each entry must say what the account holds. This chapter releases one pairing and leaves one for later, where a pairing is a lesson that joins earlier topics into one decision.

### Pairing Taught In This Chapter

The lesson DP State Machines joins the prefix table from the foundations chapter with the modes from the first two lessons. The prefix table supplies the meaning of an entry for the days seen so far. The modes supply the label, which lists the legal next moves. The lesson adds one idea: a state is a pair of a label and a count, and every transition names the pair it leaves and the pair it enters. Its four exercises report the days of the best trade, count waiting days on an optimal plan, charge a fee on the buy with a minimum profit, and allow k trades.

### Pairing That Waits For A Later Chapter

Problems that choose a set of positions, such as ranges of a tree or masks of chosen items, need states that this chapter does not teach. Chapter 29 owns interval and bit mask tables, and it builds on the range table from the last lesson of this chapter.
