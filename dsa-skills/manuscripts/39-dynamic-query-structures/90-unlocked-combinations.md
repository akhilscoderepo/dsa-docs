## Unlocked Combinations

A backup server records which byte ranges of a 2 TB file have arrived and must report the missing ranges while chunks keep coming. A separate directory service keeps an org chart and answers who sits 25 levels above an employee, thousands of times per run, while reporting lines change. The first service needs sorted ranges and coverage counts over huge offsets. The second needs indexes that survive updates. The two closing lessons pair those techniques.

These two lessons combine techniques from lessons 1 to 6 of this chapter.

### Pairings Taught In This Chapter

| Combination | Representative problem |
| --- | --- |
| Sorted Search + Coverage Counting | Gap-Tolerant Stream Summary and Dynamic Coverage API |
| Ancestor and Path Indexes + Call Workload | LeetCode 1483 Kth Ancestor of a Tree Node and LeetCode 1724 Limit Queries on a Growing Graph |

The lesson Ordered Interval State requires an explicit endpoint rule and a choice between sorted runs and a tree over the coordinate domain. The lesson Preprocessed Query APIs requires the update-to-query ratio before it keeps any index. Fenwick and segment trees stay in chapter 31.
