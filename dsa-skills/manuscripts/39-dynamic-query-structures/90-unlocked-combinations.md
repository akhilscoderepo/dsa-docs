## Unlocked Combinations

A calendar service stores booked time ranges and answers how many minutes are booked. It also exposes a lookup that returns the shortest route between two offices, and the office network changes during the day. The first feature needs sorted ranges that merge on insert. The second needs an index that survives new edges. The two closing lessons pair those techniques.

These two lessons combine techniques from lessons 1 to 6 of this chapter.

### Pairings Taught In This Chapter

| Combination | Representative problem |
| --- | --- |
| Ordered Set + Intervals | LeetCode 352 Data Stream as Disjoint Intervals |
| Graph and Tree Preprocessing + API | LeetCode 2642 Design Graph With Shortest Path Calculator |

The lesson Ordered Interval State requires an explicit endpoint rule and a choice between sorted runs and a tree over the coordinate domain. The lesson Preprocessed Query APIs requires the update-to-query ratio before it keeps any index. Fenwick and segment trees stay in chapter 31.
