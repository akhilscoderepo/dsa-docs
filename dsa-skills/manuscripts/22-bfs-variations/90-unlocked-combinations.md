## Unlocked Combinations

A rotting-orange counter reports the right four minutes but needs far too long on a large grid, because it ran one search per rotten orange. The fix changes what the queue holds at the start, not the search itself. This chapter releases one pairing in full. A second pairing waits for weighted edges.

### Pairing Taught In This Chapter

Ordinary breadth-first search gives the layer order, and state modeling decides what one vertex is. The lesson Model The State Before Searching joins them. The search supplies first-discovery distance. The modeling step supplies the start set, the visited key, the move rule and the meaning of one layer. The lesson adds one idea: those four choices are written down before any loop is coded, and a changed contract changes one of them.

### Pairing That Waits For A Later Chapter

Heap-ordered and deque-ordered frontiers need weighted relaxation, because first discovery no longer gives the smallest cost. Chapter 24 teaches both, so this chapter assigns no exercises for them.
