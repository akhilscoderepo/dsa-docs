## Unlocked Combinations

A game server must award one reward among those a player qualifies for, and a navigation service must trust a guess that comes from a table. The first needs a probability argument over a set that a data structure decides. The second needs a graph and a test of its guess. The two lessons that close this chapter pair the techniques in these examples.

These two lessons combine techniques from lessons 1 to 6 of this chapter and from earlier chapters.

### Pairings Taught In This Chapter

| Combination | Representative problem |
| --- | --- |
| Randomized State + Sampling Structure | LeetCode 398 Random Pick Index |
| Graph + A-Star Heuristic | Route search with a tested guess |

The lesson Randomized Sampling State states for each tool what its denominator is: the running eligible total for a pass, the last prefix total for tickets, and the area ratio for rejection. The lesson A-Star Heuristics states which of the two properties of a guess it relies on at each step. No further core combination is deferred from this chapter.
