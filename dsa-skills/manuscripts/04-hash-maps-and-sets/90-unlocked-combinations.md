## Unlocked Combinations

Two combinations are released by this chapter, because every prerequisite is now taught, and each has its own lesson and its own four-step ladder.

### Teach Now

Strings with hash maps is the lesson on strings and maps. Chapter 03 supplied scans, construction and fixed-alphabet counts, and this chapter supplied maps that remember counts and pairings, so the lesson can cover first unique character, anagrams, isomorphic strings and word patterns. Its false friend is a scan that remembers only the previous character. Matrices with hash sets is the lesson on matrices and sets. Chapter 02 supplied coordinates and Chapter 04 supplied membership, so the lesson covers uniqueness inside rows, columns and boxes and ends with the validity check of a Sudoku board. Its false friend is one global set.

### Deferred

Strings with maps and sorting is deferred to Chapter 05, which supplies canonical sorted signatures. This chapter groups anagrams with a letter-count key, which needs no sorting, and the sorted-signature alternative waits until sorting has been taught. No exercise here assigns a problem that needs it.

### Already Covered

The frequency array from Chapter 01 and the letter table from Chapter 03 return here as the direct-address table, framed as a choice between representations and not as a new technique. The set-based run counting of the membership lesson returns in the set-sequences lesson with a different contract, and the duplicate-detection idea from Chapter 01 returns in the first lesson with a set in place of sorting.
