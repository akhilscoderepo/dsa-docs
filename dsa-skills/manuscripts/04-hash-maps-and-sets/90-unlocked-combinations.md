## Unlocked Combinations

Maps and sets open two pairings with earlier chapters, and this chapter teaches both as lessons with their own exercises. A third pairing needs a tool that Chapter 05 owns, so this page only names it.

### Pairings Taught In This Chapter

Strings with maps is the lesson Strings And Maps. A string scan fixes the order of the characters, and a map remembers counts or character pairings. The lesson covers counting letters across two strings, checking a one-to-one renaming, and matching words to a pattern.

Matrices with sets is the lesson Matrices And Sets. Coordinates name the row, the column and the block of a cell, and a set for each group remembers the digits it holds. The lesson ends with the full rule set of a number-puzzle board.

### A Pairing That Waits For Chapter 05

Strings with maps and sorting belongs to Chapter 05, which teaches sorting and comparators. Sorted letters of a word form a signature that groups anagrams without a count table. The grouping lesson here builds its signature from letter counts, so no exercise in this chapter needs a sort.

### What Later Chapters Reuse

Three ideas carry forward.

- **The map with a stated meaning for its values** returns in every chapter that stores counts, positions or lists.
- **Prefix state kept in a map** returns in Chapter 07, where a running total plays the part of the key.
- **Record keys with a fixed order of fields** return in the graph chapters, where a pair of nodes or a grid cell names a state.
