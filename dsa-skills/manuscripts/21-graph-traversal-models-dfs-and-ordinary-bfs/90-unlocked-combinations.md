## Unlocked Combinations

Of the combinations considered for this chapter, one is released with a lesson and a ladder of its own, and one is held back with the chapter that owns it.

### Teach Now

A board read as a graph is the tenth lesson. The matrix of Chapter 02 supplies implicit vertices and neighbours through a table of steps, and the traversal of this chapter supplies the shared mark and the outer scan that finds each group once. The point that needs care is the decision about which cells count as neighbours, since wrap-around, diagonals and equal values each change the graph without changing the loop. The ladder re-asks four well-known problems with changed contracts: a recolouring on a board whose columns wrap, an island count with a diagonal switch, a report on the largest island with its ties, and a copy of a graph built from cell values that repeat. The false friend is treating equal values as one vertex.

### Deferred

Starting a search from many cells at once, or from both ends at once, is not assigned here. Both need a different first frontier and a different stopping argument, which the single-source search of the seventh lesson does not supply. Chapter 22 owns them, so no multi-source or bidirectional exercise appears in this chapter. Weighted edges are likewise left to the shortest-path chapter, and union-find as a second way to count groups waits for Chapter 23.

### Already Covered

The queue and stack used for frontiers come from Chapter 11, and the hash map used as an identity table was introduced in Chapter 04. Heap-ordered searches that pop the cheapest vertex belong to Chapter 17 together with later shortest-path work, so nothing here reopens them.
