## Unlocked Combinations

A maximum over the last thousand readings looks like a job for a loop until a deque keeps only the readings that can still win. This chapter releases one pairing that its prerequisites allow, and it names one pairing that waits for graph chapters.

### Pairing Taught In This Chapter

A deque and a sliding window form the lesson Slide A Window With Two Deques. The window supplies the moving boundaries, and the deques supply the largest and the smallest value of the window. The lesson adds one idea: a window that keeps its spread inside a limit can count every valid stretch in one pass, because every subarray of a valid window is valid. Its exercises cover a trace of the two removal passes, the smallest window maximum, a count of stretches inside a limit, and the shortest run that reaches a target with its start position.

### One Pairing Waits For Graph Chapters

A deque that serves cheap moves before costly ones appears in zero-one search on a graph. That search needs graph state and a proof about shortest paths, and neither exists yet. Chapters 21 and 24 own that pairing, and this chapter assigns none of its problems.

### What Later Chapters Reuse

Three ideas carry forward.

- **The two jobs of the ends** return whenever a later structure removes by age at one end and by quality at the other.
- **Prefix positions as candidates** return whenever a later problem has negative values and a target total.
- **The fixed step order** returns whenever a later method must expire, read, remove and append in a set sequence.
