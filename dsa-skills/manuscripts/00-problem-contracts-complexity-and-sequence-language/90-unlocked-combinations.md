## Unlocked Combinations

This chapter teaches no combination of techniques. It introduces analysis skills, not a standalone technique that could combine with an earlier one. Chapter 00 is the first chapter, so no earlier technique exists to combine with.

### Combinations Taught In Later Chapters

Chapter 04 covers arrays with hash maps, because it teaches key-to-state lookup. Chapter 08 covers arrays with two pointers, because it teaches two-boundary movement. Prefix sums, binary search and sorting each have their own chapters. The complexity arguments from this chapter apply to them without change.

Several exercises point forward on purpose. The range-sum query exercise stops at deciding that a faster plan is needed. Chapter 07 supplies the plan. No exercise in this chapter assigns a problem whose solution needs a technique you have not learned.
