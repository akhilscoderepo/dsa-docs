## Unlocked Combinations

A task service lets an operator run the best task of one user, while a worker runs the best task of the whole system. A different service seats exam students in a row of a billion seats and must find the widest gap after every arrival. The first service needs one removal path for two sorted views. The second needs candidates that check their own neighbors. The two closing lessons pair those techniques.

These two lessons combine techniques from the first six lessons of this chapter, from Multi-Index Records to Transaction Lifecycles.

### Pairings Taught In This Chapter

| Combination | Representative problem |
| --- | --- |
| Record Map + Sorted Index | LeetCode 2349 Design a Number Container System and LeetCode 3408 Design Task Manager |
| Free Resources + Priority Heap | LeetCode 1845 Seat Reservation Manager and LeetCode 855 Exam Room |

The lesson Look Up By ID And By Order requires one helper for every exit of a record. The lesson Pick The Best Free Resource requires a check of both neighbors before a candidate is used. The cache designs with linked lists stay in the earlier design chapter.
